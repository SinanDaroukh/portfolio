# Brouillons

Fichiers hors de `content/`, donc non publiés.

- `article-exemple.md` : modèle d'article. Pour publier un article, copier ce
  fichier dans `content/articles/<slug>.md` (l'URL sera `/articles/<slug>`).
  Le front-matter suit le schéma de la collection `articles`
  (`content.config.ts`) ; `date` au format ISO (`2026-02-04`). Dès qu'un
  article existe, la section Articles réapparaît (menu, accueil, sitemap).
